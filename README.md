# Data Science · Praktikum · Hochschule Ruhr West

Notebooks und Daten für das Praktikum *Data Science* (B.Sc. Wirtschaftsinformatik, WiSe 2026/27).
Die Musterlösungen stehen nach jeder Sitzung in Moodle.

## Notebook öffnen

| Woche | Praktikum | Vorlesung |
|---|---|---|
| 1 | [W1 Praktikum in Colab öffnen](https://colab.research.google.com/github/ZhuosHub/Data_Science_HRW_Praktikum/blob/main/W1/W1_Praktikum_Starter.ipynb) | [W1 Vorlesung in Colab öffnen](https://colab.research.google.com/github/ZhuosHub/Data_Science_HRW_Praktikum/blob/main/W1/Vorlesung/W1-Vorlesung.ipynb) |

1. Link anklicken: Das Notebook öffnet sich in Google Colab.
2. Oben rechts mit Ihrem Google-Konto anmelden.
3. **Datei → Kopie in Drive speichern** (engl. *File → Save a copy in Drive*). Ab jetzt arbeiten Sie in Ihrer eigenen
   Kopie; sie liegt in Ihrem Google Drive im Ordner *Colab Notebooks*.
4. Erste Zelle ausführen: `Shift + Enter`. Die Daten lädt das Notebook selbst aus diesem Repository.

**Ohne Google-Konto:** *Code → Download ZIP*, entpacken und das Notebook lokal in Jupyter öffnen (z. B. mit Anaconda).
Die Daten liegen dann schon in `data/olist/`.
